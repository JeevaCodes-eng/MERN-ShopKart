# MERN-ShopKart
A demo e-commerce application built with React + Express. Includes product browsing, registration/login, wishlist, cart, checkout and orders.

## Run locally
1. Install Node.js (LTS).
2. Open terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`

Frontend: http://localhost:5173
Backend: http://localhost:5000

Demo app uses localStorage on the frontend so core flows work without MongoDB configuration. Backend API starter is included in `server/`.
